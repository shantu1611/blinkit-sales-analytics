# 🛒 Blinkit Grocery Sales Analysis | Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Blinkit Grocery Sales Analysis Dashboard** built using Microsoft Power BI. It analyzes grocery sales performance across different product categories, fat content types, outlet locations, outlet sizes, and establishment years.

The dashboard provides business insights into sales trends, product performance, and outlet characteristics to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall grocery sales performance.
- Understand sales distribution by item type and fat content.
- Compare outlet performance based on location and size.
- Examine sales trends across different outlet establishment years.
- Identify key business metrics and performance indicators.

## 📌 Dashboard Features

### Key Performance Indicators (KPIs)
- **Total Sales:** Overall revenue generated.
- **Average Sales:** Average sales value.
- **Number of Items:** Total number of items sold/listed in the dataset.
- **Average Rating:** Average customer rating.

### Visualizations

| Visualization | Analysis |
|---|---|
| Donut Chart | Sales by Item Fat Content |
| Bar Chart | Fat Content by Outlet |
| Bar Chart | Sales by Item Type |
| Line Chart | Outlet Establishment Year Analysis |
| Donut Chart | Sales by Outlet Size |
| Funnel Chart | Sales by Outlet Location |
| Matrix/Table | Outlet Type Performance |

### Interactive Filters
- Item Type
- Outlet Location
- Outlet Size
- Fat Content

## 🚀 How to Use

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `BlinkIT.pbix` file.
4. If prompted, update the dataset source path.
5. Refresh the data if required.
6. Explore the dashboard using interactive filters and visualizations.
